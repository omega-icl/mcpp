Dense Chebyshev Model Arithmetic for Factorable Functions

The classes mc::CModel and mc::CVar provide an implementation of dense Chebyshev model arithmetic. The polynomial part is propagated in floating-point arithmetic, with preallocation of the full coefficient array. In that respect, The remainder term is propagated in the arithmetic of the templated type, typically a verified interval arithmetic. Rounding errors are not accounted for during the polynomial propagation, so mc::CModel and mc::CVar do not provide a fully verified implementation.

How do I compute a dense Chebyshev model with interval remainder bound of a factorable function?

Suppose we want to compute a 4th-order dense Chebyshev model for the real-valued function \(f(x,y)=x\exp(y^2)-y^2\) with \((x,y)\in [1,2]\times[0,1]\). For simplicity, bounds on the remainder terms are computed using the default interval type mc::Interval here:

#include "interval.hpp"
#include "cmodel.hpp"
typedef mc::Interval I;
typedef mc::CModel<I> CM;
typedef mc::CVar<I> CV;

First, the number of independent variables in the factorable function ( \(x\) and \(y\) here) as well as the order of the polynomial inclusion (4th order here) are specified by defining an mc::CModel object as:

CM mod( 2, 4 );

Next, the variables \(x\) and \(y\) are defined as follows:

CV X( &mod, 0, I(1.,2.) );
CV Y( &mod, 1, I(0.,1.) );

Essentially, the first line means that X is a variable of class mc::CVar, participating in the Chebyshev model mod, belonging to the interval \([1,2]\), and having index 0 (C-style indexing in use). The same holds for the variable Y, participating in the model mod, belonging to the interval \([0,1]\), and having index 1.

Having defined the variables, a dense Chebyshev model of \(f(x,y)=x\exp(x+y^2)-y^2\) on \([1,2]\times[0,1]\) at the mid-point \((\frac{3}{2},\frac{1}{2})\) is computed as:

CV F = X*exp(pow(Y,2))-pow(Y,2);

This model can be displayed to the standard output as:

std::cout << "f dense Chebyshev model: " << F << std::endl;

which produces the following output:

Other operations involve retreiving the remainder bound, or computing the value of its polynomial part at a given point:

I B = F.B();
double x[2] = { 1.5, 0.5 };
double Pval = F.P( x );

See the documentations of mc::CModel and mc::CVar for a complete list of member functions.

Which functions are overloaded for dense Chebyshev model arithmetic?

mc::CVar overloads the usual functions exp, log, sqr, sqrt, pow, inv, cos, sin, tan, acos, asin, atan, cosh, sinh, tanh, fabs. The functions erf, erfc, min, max, fstep, and bstep are not currently overloaded in mc::CVar. Moreover, mc::CVar defines the following functions:

  • inter(x,y,z), computing a Chebyshev model of the intersection \(x = y\cap z\) of two Chebyshev models and returning true/false if the intersection is nonempty/empty. With Chebyshev models \(\mathcal P_y\oplus\mathcal R_y\) and \(\mathcal P_z\oplus\mathcal R_z\), this intersection is computed as follows:

    \begin{align*} \mathcal P_{x} =\ & (1-\eta) \mathcal P_y^{\rm C} + \eta \mathcal P_z^{\rm C}\\ \mathcal R_{x} =\ & [\mathcal R_y^{\rm C}\oplus\eta\mathcal{B}(\mathcal P_y^{\rm C}-\mathcal P_z^{\rm C})] \cap [\mathcal R_z^{\rm C}\oplus (1-\eta)\mathcal{B}(\mathcal P_z^{\rm C}-\mathcal P_y^{\rm C})]\,. \end{align*}

    with \(\mathcal{B}(\cdot)\) the Chebyshev model range bounder, and \(\eta\) a real scalar in \([0,1]\). Choosing \(\eta=1\) amounts to setting the polynomial part \(\mathcal P_{x}\) as \(\mathcal P_y\), whereas \(\eta=0\) sets \(\mathcal P_{x}\) as \(\mathcal P_z\). The parameter \(\eta\) can be defined in mc::CModel::Options::REF_POLY.
  • hull(x,y), computing a Chebyshev model of the union \(x = y\cup z\) of two Chebyshev models. With Chebyshev models \(\mathcal P_y\oplus\mathcal R_y\) and \(\mathcal P_z\oplus\mathcal R_z\), this union is computed as follows:

    \begin{align*} \mathcal P_{x} =\ & (1-\eta) \mathcal P_y^{\rm C} + \eta \mathcal P_z^{\rm C}\\ \mathcal R_{x} =\ & {\rm hull}\{\mathcal R_y^{\rm C}\oplus\eta\mathcal{B}(\mathcal P_y^{\rm C}-\mathcal P_z^{\rm C}), \mathcal R_z^{\rm C}\oplus (1-\eta)\mathcal{B}(\mathcal P_z^{\rm C}-\mathcal P_y^{\rm C})\}\,. \end{align*}

    with \(\mathcal{B}(\cdot)\) and \(\eta\) as previously.

How are the options set for the computation of a dense Chebyshev model?

The class mc::CModel has a public member called mc::CModel::options that can be used to set/modify the options. For instance:

mod.options.BOUNDER_TYPE = CM::Options::EIGEN;
mod.options.SCALE_VARIABLES = true;

The available options are the following:

Errors What errors can I encounter during computation of a dense Chebyshev model?

Errors are managed based on the exception handling mechanism of the C++ language. Each time an error is encountered, a class object of type mc::CModel::Exceptions is thrown, which contains the type of error. Possible errors encountered during the computation of a dense Chebyshev model are:

Errors from class mc::CModel::Exceptions during the Computation of a Chebyshev Model
Number Description
1 Division by zero scalar
2 Inverse operation with zero in range
3 Log operation with non-positive numbers in range
4 Square-root operation with negative numbers in range
5 Tangent operation with (k+1/2)·PI in range
6 Sine/Cosine inverse operation with range outside [-1,1]
7 Failed to compute eigenvalue decomposition in range bounder CModel::Options::EIGEN
-1 Failed to construct Chebyshev variable
-2 Chebyshev model bound does not intersect with bound in template parameter arithmetic
-3 Operation between Chebyshev variables linked to different Chebyshev models
-4 Internal error
-33 Feature not yet implemented in mc::CModel

The base class mc::PolyModel may also throw an exception of type mc::PolyModel::Exceptions, with the following codes:

Errors from base class mc::Polymodel::Exceptions during the Computation of a Chebyshev Model
Number Description
1 Inconsistent polynomial model dimension
2 Maximum size in polynomial model reached

Further exceptions may be thrown by the template parameter class itself.
