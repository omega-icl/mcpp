The classes mc::SElimEnv and mc::SElimVar defined in selim.hpp enable the elimination of a subset of variables from factorable expressions through expoiting solvable (invertible) equality constraints.

What is the algorithm used for the elimination?

Given a set of equality constraints \({\bf f}({\bf x}) = {\bf 0}\) with \({\bf f}:\mathbb{R}^n\to\mathbb{R}^m\) and \(n\geq m\), we seek to partition the variable set into \({\bf x} =: [{\bf x}_{\rm indep},{\bf x}_{\rm dep}]\), where \({\bf x}_{\rm indep}\in\mathbb{R}^{n_{\rm indep}}\) and \({\bf x}_{\rm dep}\in\mathbb{R}^{n_{\rm dep}}\) are the independent and dependent decisions, respectively; and to construct an explicit mapping \({\bf g}:\mathbb{R}^n\to\mathbb{R}^m\) such that \({\bf x}_{\rm dep} = {\bf g}({\bf x}_{\rm indep})\).

This elimination proceeds in 3 steps:

  1. Identify which equality constraints can be inverted analytically in terms of which variables.
  2. Determine which variables to eliminate using which equality constraints, e.g. to maximize the number of eliminated variables, based on: (i) a mixed-integer programming (MIP) formulation; or (ii) a greedy heuristic inspired by the method of Hernandez & Sargent (1979) to reorder the equations then select the variables through reordering the incidence matrix to bordered lower-triangular form.
  3. Construct expressions for the eliminated variables, so they can be eliminated through composition.

The MIP formulation solves the following problem using Gurobi:

\begin{align*}\displaystyle\min_{\boldsymbol{v},\boldsymbol{c},\boldsymbol{d},\boldsymbol{e},\boldsymbol{z}}\ & \sum_{i=1}^{\bar{V}} \omega_i v_i\\ \displaystyle\text{s.t.}\ \ \ & \sum_{k\in E_i} e_{i,k} = v_i,\ \ i=1\ldots\bar{V}\\ & \sum_{i\in C_k} e_{i,k} = c_k,\ \ k=1\ldots\bar{C}\\ & d_{i,j} \leq v_i,\ \ i=1\ldots\bar{V},\ j\in D_i\\ & d_{i,j} \geq e_{i,k},\ \ k=1\ldots\bar{C},\ i\in C_k,\ j\in D_i \cap V_k\\ & d_{i,j} + e_{i,k} \leq 1,\ \ k=1\ldots\bar{C},\ i\in C_k,\ j\notin D_i \cap V_k\\ & z_i - z_j \leq (1-d_{i,j})\bar{V}-1,\ \ i=1\ldots\bar{V},\ j\in D_i\\ & v_i, d_{i,j}, c_k, e_{i,k}\in\{0,1\},\ \ z_i\in [0,\bar{V}-1] \end{align*}

with the following sets, parameters and variables:

  • \(E_i\subset\{1,\ldots,\bar{C}\}\) subset of candidate constraints for variable \(i\) elimination
  • \(D_i\subset\{1,\ldots,\bar{V}\}\) subset of candidate variables for variable \(i\) elimination
  • \(V_k\subset\{1,\ldots,\bar{V}\}\) subset of variables participating in constraint \(k\)
  • \(C_k\subset\{1,\ldots,\bar{V}\}\) subset of candidate variables for elimination participating in constraint \(k\)
  • \(\omega_i\in\{0,1\}\) weight coefficient for variable \(i=1\ldots \bar{V}\)
  • \(v_i\in\{0,1\}\) encoding whether variable \(i=1\ldots \bar{V}\) is selected for elimination
  • \(c_k\in\{0,1\}\) encoding whether constraint \(k=1\ldots \bar{C}\) is selected for elimination
  • \(d_{i,j}\in\{0,1\}\) encoding whether variable \(j\in D_i\) is used to eliminate variable \(i=1\ldots \bar{V}\)
  • \(e_{i,k}\in\{0,1\}\) encoding whether constraint \(k\in E_i\) is selected to eliminate variable \(i=1\ldots \bar{V}\)
  • \(z_i\in[0,\bar{V}-1]\) encoding precedence in MTZ subtour elimination

How do I eliminate variables using factorable equality constraints?

For illustration, consider the following pair of nonlinear equality constraints in three variables \(x_0,x_1,x_2\):

\begin{align*} 0 &= \frac{3x_0(x_2)^2}{x_1} - 2x_0x_1 - x_0 - 1\\ 0 &= \frac{2}{x_1} + \frac{3}{x_2} - 1 \end{align*}

The elimination requires the header file selim.hpp to be included:

#include "selim.hpp"

A DAG of the factorable function defining the equality constraints is first created:

mc::FFGraph DAG;
const unsigned NX = 3, NF = 2;
mc::FFVar X[NX];
for( unsigned i(0); i<NX; i++ ) X[i].set( &DAG );
mc::FFVar F[NF];
F[0] = ( 3. * X[0] * sqr( X[2] ) ) / X[1] - 2. * X[0] * X[1] - X[0] - 1;
F[1] = 2./X[1] + 3./X[2] - 1.;
std::cout << DAG;

These results show that both variables \(x_0\) and \(x_2\) can be eliminated through inverting both equality constraints.

  • The expression of variable \(x_2\) in terms of \(x_1\) is given by:

    \begin{align*} x_2 &= \frac{3}{\displaystyle 1-\frac{2}{x_1}} \end{align*}

  • The expression of variable \(x_0\) in terms of \(x_1\) and \(x_2\)—where \(x_2\) could be eliminated recursively in terms of \(x_1\) using the previous expression—is given by:

    \begin{align*} x_0 &= \frac{1}{\displaystyle 3\frac{(x_2)^2}{x_1} - 2x_1 - 1} \end{align*}

The method mc::SElimEnv::VarElim allows retreiving a 3-tuple of vectors of (i) the eliminated variables, (ii) the original constraint used for the elimination, and (iii) the inverted constraint expression, with entries in a feasible order of elimination (lower-triangular form).
