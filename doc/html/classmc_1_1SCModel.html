Detailed Description

template<typename T, typename KEY = unsigned, typename COMP = std::less<unsigned>>
class mc::SCModel< T, KEY, COMP >

mc::SCModel is a C++ class for definition of Chebyshev model environment in sparse format. Propagation of sparse Chebyshev models for factorable functions is via the C++ class mc::SCVar. The template parameter corresponds to the type used to propagate the remainder bound.
