Detection of Reduction Constraints in Sparse Polynomial Constraints
Author
Benoit Chachuat
Date
2023

The class mc::SRed defined in sred.hpp identifies reduction constraints from a given set of sparse polynomial equality constraints. The starting point is the reduced RLT approach introduced by Liberti (2004) and Liberti & Pantelides (2006), which uses graph theory to identify new quadratic constraints from existing linear equality constraints and participating bilinear terms, namely reduction constraints. The class mc::SRed generalizes this approach in three ways:

  • It searches for new polynomial equality constraints based on existing polynomial equality constraints and participating monomial terms;
  • It enables the formation of reduction constraint both through multiplication and division of existing polynomial equality constraints with (monomials of) the participating variables;
  • It conducts the search via an integer-programming-based approach that supersedes the original graph-theoretic approach by Liberti & Pantelides (2006).

In essence, mc::SRed identifies linearity embedded into polynomial programs and may be applied as a pre-processing step to simplify polynomial programs in practice.

How Does the Detection Algorithm Work?

The starting point is a set of participating monomials, \(\mathcal{M} := \{ m_i({\bf v}) \}_{1\leq i\leq n_{\rm mon}}\) and polynomial equality constraints,

\begin{align*} \sum_{k=1}^{M_\lambda} a_{\lambda,k}\cdot m_{\lambda,k}({\bf v}) =\ & 0,\ \ \lambda\in 1\ldots n_{\rm pol} \end{align*}

with monomials \(m_{\lambda,k}({\bf v})\) in the variables \(v_j\), \(1\leq j\leq n_{\rm var}\).

The first step entails identifying of those polynomial constraints which, when multiplied or divided by a given variable (or more generally monomial), lead to the creation of fewer new monomials than extra constraints. Liberti & Pantelides (2006) proposed a graph-theoretical approach to identify a valid assignment. Instead, the class mc::SRed constructs and solves the following integer linear program (ILP) to identify an optimal assignment:

\begin{align*}\min &\ \sum_{j=1}^{n_{\rm var}} \left[ (1+\epsilon)\sum_{i=1}^{n_{\rm mon}} \left(h_{i,j}+l_{i,j}\right) - \sum_{\lambda=1}^{n_{\rm pol}} \left(d_{\lambda,j}+m_{\lambda,j}\right) \right]\\ \text{s.t.}\ &\ h_{i,j} \geq m_{\lambda,j}, \ \ \forall i\in\mathcal{M}_{\lambda,j}, \forall j,\lambda\\ &\ l_{i,j} \geq d_{\lambda,j}, \ \ \forall i\in\mathcal{D}_{\lambda,j}, \forall j,\lambda\\ &\ h_{i,j},l_{i,j},m_{\lambda,j},d_{\lambda,j}\in\{0,1\},\ \ \forall i,j,\lambda\,. \end{align*}

  • The binary variables have the following interpretation:

    \begin{align*}m_{\lambda,j} :=\ & \left\{\begin{array}{ll} 1 & \text{if polynomial constraint $\lambda\in 1\ldots n_{\rm pol}$ is multiplied by variable $v_j, j\in 1\ldots n_{\rm var}$}\\ 0 & \text{otherwise} \end{array}\right.\\ d_{\lambda,j} :=\ & \left\{\begin{array}{ll} 1 & \text{if polynomial constraint $\lambda\in 1\ldots n_{\rm pol}$ is divided by variable $v_j, j\in 1\ldots n_{\rm var}$}\\ 0 & \text{otherwise} \end{array}\right.\\ h_{i,j} :=\ & \left\{\begin{array}{ll} 1 & \text{if the higher-degree monomial $m_i({\bf v})\cdot v_j$ is created, that is, $m_i({\bf v})\cdot v_j\notin \mathcal{S}_{\rm mon}$}\\ 0 & \text{otherwise} \end{array}\right.\\ l_{i,j} :=\ & \left\{\begin{array}{ll} 1 & \text{if the lower-degree monomial $m_i({\bf v})/ v_j$ is created, that is, $m_i({\bf v})/ v_j\notin \mathcal{S}_{\rm mon}$}\\ 0 & \text{otherwise} \end{array}\right. \end{align*}

  • The index sets \(\mathcal{M}_{\lambda,j}\) and \(\mathcal{D}_{\lambda,j}\) associated with each polynomial constraint \(\lambda\in 1\ldots n_{\rm pol}\) and each multiplier or divider variable \(v_j, j\in 1\ldots n_{\rm var}\), respectively, are given by:

    \begin{align*}\mathcal{M}_{\lambda,j} :=\ & \left\{ i~\middle| a_{\lambda, i} \neq 0 \wedge m_i({\bf v})\cdot v_j\notin \mathcal{S}_{\rm mon} \right\}\\ \mathcal{D}_{\lambda,j} :=\ & \left\{ i~\middle| a_{\lambda, i} \neq 0 \wedge m_i({\bf v})/ v_j\notin \mathcal{S}_{\rm mon} \right\} \end{align*}

    This way, given \(i\in\mathcal{M}_{\lambda,j}\) for some \(j\in 1\ldots n_{\rm var}\) and \(\lambda\in 1\ldots n_{\rm pol}\), the cut \(h_{i,j} \geq m_{\lambda,j}\) accounts for the creation of the new monomial \(m_i({\bf v})\cdot v_j\) on multiplying constraint \(\lambda\) with variable \(v_j\); likewise, given \(i\in\mathcal{D}_{\lambda,j}\) for some \(j\in 1\ldots n_{\rm var}\) and \(\lambda\in 1\ldots n_{\rm pol}\), the cut \(l_{i,j} \geq d_{\lambda,j}\) accounts for the creation of the new fractional term \(m_i({\bf v})/ v_j\) on dividing constraint \(\lambda\) with variable \(v_j\).
  • Finally, the factor \((1-\epsilon)\) multiplying the binary variables \(b_{i,j}\) and \(f_{i,j}\) in the objective function penalizes assignments that create as many new constraints as bilinear terms – which would otherwise add up to zero in the objective function and yield a large number of (globally optimal) solutions for the ILP. The objective in doing so is therefore to determine those assignments yielding a minimal assignment.

Notice that taking all of the binary variables \(h_{i,j},l_{i,j},m_{\lambda,j},d_{\lambda,j}\) equal to 0 gives a feasible solution to the ILP with an objective of 0. Of interest for us, of course, are optimal solution with a strictly negative objective, so that exactly \(M-N>0\) reduction constraints could be identified, with \(M:=\sum_{j=1}^{n_{\rm var}} \sum_{\lambda=1}^{n_{\rm pol}} (d_{\lambda,j}+m_{\lambda,j})\) and \(N:=\sum_{j=1}^{n_{\rm var}} \sum_{i=1}^{n_{\rm pol}} (h_{i,j}+l_{i,j})\).

In order to recover their symbolic expressions, we proceed by first writing the complete set of new polynomial constraints obtained from the multiplication or division of existing polynomial constraints with variables,

\begin{align*}\forall (\lambda,j): m_{\lambda,j}=1, \quad & \sum_{k=1}^{M_\lambda} a_{\lambda,k} \cdot m_{\lambda,k}({\bf v})\cdot v_j = 0\\ \forall (\lambda,j): d_{\lambda,j}=1, \quad & \sum_{k=1}^{M_\lambda} a_{\lambda,k} \cdot m_{\lambda,k}({\bf v})/ v_j = 0 \end{align*}

These constraints can be rewritten in matrix form as

\begin{align*} {\bf A}\cdot{\bf n}({\bf v}) = & {\bf b}({\bf v}) \end{align*}

where:

  • \({\bf b}({\bf v})\) is an \(M\)-dimensional vector, with entries

    \begin{align*} {\bf b}({\bf v}) & := \left( \begin{array}{ll} \forall (\lambda,j): m_{\lambda,j}=1, & \sum_{i: m_i({\bf v})\cdot v_j\notin \mathcal{S}_{\rm mon}} a_{\lambda,i}\cdot m_i({\bf v})\cdot v_j \\ \forall (\lambda,j): d_{\lambda,j}=1, & \sum_{i: m_i({\bf v})/ v_j\notin \mathcal{S}_{\rm mon}} a_{\lambda,i}\cdot m_i({\bf v})/ v_j \end{array} \right) \end{align*}

  • \({\bf n}({\bf v})\) is an \(N\)-dimensional vector, comprised of the newly created monomial terms

    \begin{align*} {\bf n}({\bf v}) & := \left( \begin{array}{cl} \forall(i,j):h_{i,j}=1, & m({\bf v})\cdot v_j \\ \forall(i,j):l_{i,j}=1, & m({\bf v})/ v_j \end{array} \right) \end{align*}

  • \({\bf A}\) is an \(M\)-by- \(N\) real matrix

Next, we perform an LU factorization of the coefficient matrix \({\bf A}\), such that \({\bf P}\cdot{\bf A}={\bf L}\cdot{\bf U}\). The bottom \(M-N>0\) rows of the vector \({\bf p}({\bf v})\) such that \({\bf L}\cdot{\bf r}({\bf v})={\bf P}\cdot{\bf b}({\bf v})\) – as obtained for instance from a simple forward elimination – are equal to zero by construction, and yield valid reduction polynomial constraints,

\begin{align*} r_{N+1}({\bf v}) & = 0\\ &\ \vdots\\ r_{M}({\bf v}) & = 0 \end{align*}

For large-scale problem, one may use efficient sparse implementations of LU factorization, based for instance on a bordered block decomposition of the original coefficient matrix – see, e.g., available routines within the Harwell Scientific Library (HSL).

How Do I Search for Reduction Constraints?

For illustration, consider the following pair of linear and quadratic constraints in three variables \(x_0,x_1,x_2\):

\begin{align*} 0 = & x_0 + x_1 - 1\\ 0 = & x_0^2 - x_1^2 - x_2 \end{align*}

The search for reduction constraints requires the header file sred.hpp to be included:

#include "sred.hpp"

Sparse polynomials are created for each constraint:

const unsigned NX = 3, NF = 2;
mc::SPoly X[NX];
for( unsigned i=0; i<NX; i++ ) X[i].var( i );
mc::SPoly F[NF];
F[0] = X[0] + X[1] - 1.;
F[1] = sqr(X[0]) - sqr(X[1]) - X[2];

These results show that the algorithm has identified the following reduction constraint:

\begin{align*} 0 =\ & x_0 - x_1 + x_0^2 - x_1^2 \end{align*}

It is easy to check that this new constraint is obtained upon multiplying the existing linear constraint \(0 = x_0 + x_1 - 1\) with either variable \(x_0\) or \(x_1\) then subtracting them to eliminate the cross-term \(x_0x_1\). Notice also that the solution set of the new reduction constraint is \(\left\{x_0,x_1\middle| x_0+x_1=1 \vee x_0-x_1=0 \right\}\), which is indeed redundant with the original constraint \( x_0+x_1=1\).

What are the options in mc::SRed and how do I set them?

The public static class member mc::SRed::options that can be used to set/modify the options; e.g.,

mc::SQuad::options.ORDER = 2;
mc::SQuad::options.MIPDISPLEVEL = 1;

What Errors Can Be Encountered during the Quadratization of a Multivariate Polynomial?

Errors are managed based on the exception handling mechanism of the C++ language. Each time an error is encountered, a class object of type mc::SQuad::Exceptions is thrown, which contains the type of error. It is the user's responsibility to test whether an exception was thrown during a quadratization, and then make the appropriate changes. Should an exception be thrown and not caught, the program will stop.

Possible errors encountered during quadratization of a multivariate polynomial are:

Number Description
1 Maximal problem size reached
2 Mixed-integer programming solver disabled
3 LU decomposition failed
4 SV decomposition failed
-33 Internal error
