Detailed Description

template<typename T>
class mc::ISModel< T >

mc::ISModel is a C++ class for definition of interval superposition model (ISM) environment. ISM propagation of factorable functions is implemented via the C++ class mc::ISVar. The template parameter corresponds to the type used to propagate the interval coefficients.
