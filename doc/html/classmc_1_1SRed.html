Detailed Description

template<typename KEY = unsigned, typename COMP = std::less<unsigned>>
class mc::SRed< KEY, COMP >

mc::SQuad is a C++ class for reformulation of sparse polynomial models as a set of quadratic forms via the introduction of auxiliary variables (lifting). Sparse monomial are defined using the class mc::SPolyModel.
